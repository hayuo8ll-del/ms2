# 用語集

Claude Code のドキュメントやこの資料で出てくる用語をまとめています。五十音順ではなく、**関連するものをまとめて**並べています。

---

## 基本概念

### エージェント的ループ（agentic loop）

Claude Code の中心にある動作モデル。**「考える → ツールを使う（読む・書く・実行する）→ 結果を見る → また考える」** を目標が達成されるまで繰り返します。
チャットが「1 往復で終わる」のに対し、エージェントは自分で複数ステップを進めます。

### コンテキストウィンドウ（context window）

Claude が一度に扱える情報の上限。会話のすべて、読んだファイルの中身、コマンドの出力がここに積み上がります。
**Claude Code で最も重要な管理対象リソース**です。埋まるほど性能が落ちます。
→ [05 効果的な使い方](05-best-practices.md#5-1-すべての土台-コンテキストウィンドウ)

### コンパクション（compaction）

コンテキストが限界に近づいたとき、会話履歴を要約して容量を空ける処理。自動でも走りますし、`/compact` で手動実行もできます。

### チェックポイント（checkpoint）

プロンプトを送るたびに自動で作られる保存地点。`/rewind` や `Esc` 2回で、会話やコードをその地点に戻せます。
**Claude のファイル編集ツール経由の変更しか追跡しない**ため、git の代わりにはなりません。

### サーフェス（surface）

Claude Code が動作する場所のこと。ターミナル、VS Code、JetBrains、デスクトップアプリ、Web、モバイル、Slack、CI など。
どのサーフェスでも同じエンジンが動き、`CLAUDE.md`・設定・MCP は共通で使えます。

### 拡張思考（extended thinking）

Claude が回答の前に内部で推論を行う機能。複雑な計画・推論タスクで精度が上がりますが、**思考トークンは出力トークンとして課金されます。**
`Alt+T`（`Option+T`）で切り替え、`/effort` で努力度を調整できます。

### 高速モード（fast mode）

出力を速くするモード。**小さいモデルに切り替わるわけではありません**（Opus のまま速くなります）。`/fast` または `Alt+O` で切り替えます。

## 指示とメモリ

### CLAUDE.md

プロジェクトや個人のルールを書いておく Markdown ファイル。**毎セッションの開始時に自動で読み込まれます。**
`/init` で雛形を生成でき、200 行以内が目安です。
→ [06 CLAUDE.md とメモリ](06-claude-md.md)

### オートメモリ（auto memory）

Claude が自分で書き溜めていくメモ。ビルドコマンド、デバッグの知見、あなたの好みなどを、作業しながら記録します。
`~/.claude/projects/<project>/memory/` に保存され、マシンローカルです。

### ルール（`.claude/rules/`）

`CLAUDE.md` を分割して整理する仕組み。`paths` フロントマターを付ければ、**特定のファイルを扱うときだけ読み込まれる**ようにできます（コンテキスト節約に有効）。

## 拡張機能

### スキル（Skill）

`SKILL.md` に書いた知識や手順。**本文は使うときだけ読み込まれる**ため、長い参照資料を置いてもコンテキストをほとんど消費しません。
`/スキル名` で自分で呼び出すか、Claude が関連を判断して自動で読み込みます。
→ [08-2 スキル](08-extensions.md#skills)

### サブエージェント（Subagent）

独自のコンテキストウィンドウ・システムプロンプト・ツール権限を持つ実行単位。
**作業は別のコンテキストで行われ、メイン会話には要約だけが返ります。** コンテキスト節約の主力です。
→ [08-5 サブエージェント](08-extensions.md#subagents)

### エージェントチーム（Agent team）

複数の独立した Claude Code セッションが、共有タスクリストとメッセージで自律的に連携する仕組み。
サブエージェントと違い、**チームメイト同士が直接やり取りできます。** 実験的機能で、トークン消費が大きい点に注意。

### フック（Hook）

ライフサイクルイベント（ツール実行の前後、セッション開始・終了など）で必ず実行されるスクリプト等。
**CLAUDE.md の指示が「お願い」なのに対し、フックは「強制」です。**
→ [08-3 フック](08-extensions.md#hooks)

### MCP（Model Context Protocol）

AI ツールを外部データソースに接続するためのオープン標準。
MCP サーバーを接続すると、Claude Code がデータベース・Jira・Figma・Slack などを直接扱えるようになります。
→ [08-4 MCP](08-extensions.md#mcp)

### プラグイン（Plugin）

スキル・フック・サブエージェント・MCP サーバーを 1 つにまとめた配布可能な単位。`/plugins` で管理します。

### マーケットプレイス（Marketplace）

プラグインを配布・発見する場所。コミュニティや Anthropic のものを使えるほか、自組織用に作ることもできます。

### コードインテリジェンス

言語サーバー（LSP）と接続し、シンボル単位の正確な定義ジャンプと、編集後の型エラー自動検出を可能にする機能。
プラグインとして導入します。**型付き言語ではコンテキスト節約にも精度向上にも効きます。**

## 権限とセキュリティ

### 権限モード（permission mode）

Claude がどこまで確認なしで実行できるかの設定。`default`（Manual）/ `acceptEdits` / `plan` / `auto` / `dontAsk` / `bypassPermissions` の 6 種類。`Shift+Tab` で切り替えます。
→ [07 権限とセキュリティ](07-permissions-security.md)

### プランモード（plan mode）

Claude がファイルを読んで計画を立てるが、**ソースは変更しない**モード。「間違った問題を解く」ことを防ぐために使います。

### auto モード

別の分類モデル（classifier）が実行前に操作をレビューし、危険なものだけをブロックするモード。
承認の回数を大きく減らしつつ、バックグラウンドの安全チェックを維持できます。

### 分類モデル（classifier）

auto モードで、各操作を実行前に評価するモデル。スコープの逸脱、見知らぬインフラへの操作、悪意あるコンテンツに誘導された操作をブロックします。

### 保護されたパス（protected paths）

`.git`、`.claude`、`.bashrc`、`.npmrc` などへの書き込み。**`bypassPermissions` 以外では自動承認されません。** 設定の `allow` ルールでも上書きできません。

### サンドボックス（sandbox）

OS レベルでファイルシステムとネットワークのアクセスを制限する仕組み。範囲を限定した上で、その中では自由に動かせます。

### プロンプトインジェクション

Web ページ、Issue のコメント、CI ログなど**外部から読み込んだ内容に、悪意ある指示を仕込む攻撃**。
auto モードの分類モデル、`deny` ルール、`PreToolUse` フックが対策になります。

## セッションと実行形態

### 非対話モード（headless / print mode）

`claude -p "..."` で、対話プロンプトを出さずに実行して終了するモード。CI・スクリプト・パイプラインへの組み込みで使います。

### バックグラウンドエージェント

`claude --bg` で切り離して実行するセッション。`/tasks` で一覧、`claude attach <id>` で接続できます。

### クラウドセッション

Anthropic 管理の隔離された VM 上で動くセッション。Web 版・`claude --cloud`・Routines で作られます。

### テレポート（teleport）

クラウドセッションをローカルのターミナルに引き継ぐ機能。`claude --teleport` または `/teleport`。
`--resume`（ローカル履歴の再開）とは別物です。

### リモートコントロール（Remote Control）

**ローカルで動いているセッション**を、スマホやブラウザから操作できるようにする機能。`/remote-control`。
クラウドセッションを作る `--cloud` とは別物です。

### worktree

git の機能で、同じリポジトリの別ブランチを別ディレクトリにチェックアウトしたもの。
`claude -w <ブランチ名>` で作成でき、**並列セッションの編集が衝突しません。**

### Routines（定期実行）

Anthropic 管理のインフラ上でスケジュール実行される仕組み。**PC の電源が切れていても動きます。** API 呼び出しや GitHub イベントでも起動できます。

### Auto-fix（PR の自動修正）

CI の失敗やレビューコメントに Claude が自動で対応する機能。`/autofix-pr` などで有効化します。

## その他

### プロンプトキャッシュ（prompt caching）

システムプロンプトや会話履歴のような繰り返し送る内容をキャッシュして、コストを下げる仕組み。
**キャッシュの有効期間を過ぎると再処理が発生する**ため、長い休憩の後の最初のメッセージは割高になります。

### トークン

モデルが処理するテキストの単位。入力・出力・キャッシュ読み込み・キャッシュ書き込みで、それぞれ課金の扱いが異なります。`/usage` で確認できます。

### 努力度（effort）

モデルがどれだけ深く考えるかのレベル。`low` / `medium` / `high` / `xhigh` / `max` / `ultracode`。`/effort` で設定します。単純なタスクでは下げるとコストが減ります。

### ゴール（`/goal`）

達成すべき条件を設定すると、別の評価役が毎ターンそれをチェックし、**満たされるまで Claude が作業を続ける**仕組み。

### ツール（tool）

Claude が使える機能の単位。ファイル読み書き、検索、コマンド実行、Web 取得など。権限設定はツール単位で行います。
