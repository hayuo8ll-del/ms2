マイクラ建築図面ジェネレータ.

サイズを入れると、レイヤー（Y）ごとの平面図・立面図・コマンドが出ます — Claude Code 設定ジェネレータ

形状

公開されている建築・トラップを読む

配布サイトから落とした .litematic / .schem / .nbt を そのまま図面と材料表にします。ファイルはブラウザの中だけで読み、どこにも送信しません。

配布元から選ぶ

GitHub の公開リポジトリなら、中の .litematic / .schem / .nbt を一覧して選べます。owner/repo@branch でブランチも指定できます。 置き場を探すなら GitHub で検索して、 見つけた owner/repo を貼ってください。

ここにファイルをドロップ またはクリックして選ぶ（.litematic / .schem / .nbt）

実際の建物から起こす

建物の名前を入れて選ぶと、実寸に合わせた図面と材料表が出ます。 実測の再現ではなく、ブロックで積める形に単純化した外形です。

現実の寸法（メートル）を入れると、1 ブロック何メートルで建てるかに合わせて 基礎・壁・床・窓・玄関・屋根の図面にします。
