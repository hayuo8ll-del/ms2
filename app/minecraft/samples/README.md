# 同梱サンプル

`tools/make_samples.py` が生成した自前のデータです（第三者の作品ではありません）。
読み込みを試すためのもので、3 形式とも中身は同じです。

```
7 × 7 × 5（幅X × 奥行Z × 高さY）  ブロック 111 個
```

| ブロック | 個数 |
| --- | --- |
| `minecraft:stone_bricks` | 98 |
| `minecraft:glass` | 8 |
| `minecraft:water` | 2 |
| `minecraft:oak_stairs` | 1 |
| `minecraft:hopper` | 1 |
| `minecraft:redstone_block` | 1 |
