# マイクラ建築図面ジェネレータ

サイズを入れると、**レイヤー（Y 座標）ごとの平面図**が出る Web アプリです。

**公開 URL**: https://hayuo8ll-del.github.io/ms2/minecraft/

```
円 / 楕円 / 円柱      球 / 楕円体      ドーム（半球）    円錐 / 尖塔
切妻屋根              寄棟屋根          片流れ屋根        螺旋階段        アーチ / 橋の弧
```

---

## なぜ作ったか

マイクラで詰まるのは、たいてい**計算しないとブロックの位置が決まらない形**です。
半径 9 の球の 4 段目がどんな円になるか、幅 13 の寄棟屋根の 3 段目で階段をどっち向きに置くかは、
手で割り出すと時間がかかるうえ、途中で 1 マスずれると最後まで気づけません。

このアプリは、**サイズ → 各段の平面図**の変換だけをやります。図面を見ながら下から積めば形が出ます。
特定の建物の完成図ではなく、任意サイズに対応するパラメトリック生成に振っています。

---

## 使い方

1. ページを開く（またはこのディレクトリの `index.html` を直接開く）
2. 左で形状を選び、寸法を入れる
3. 右の平面図をスライダーか `←` `→` キーで送りながら、下の段から積む

| タブ | 中身 |
| --- | --- |
| 平面図 | 現在の段の平面図と、中心を通る立面図。一つ下の段が薄く重なる |
| 全レイヤー | 全段を並べたコンタクトシート。印刷向き |
| テキスト | 記号グリッドの図面。チャットやメモに貼れる |
| コマンド | `setblock` の列（`.mcfunction`） |

**図面 URL をコピー**を押すと、いまの寸法が入った URL が取れます。入力内容はブラウザの
localStorage にだけ保存され、外部には送信されません。

### URL パラメータ

| パラメータ | 動作 |
| --- | --- |
| `?shape=dome&rx=12&ry=8&rz=12` | 形状と寸法を指定して開く（パラメータ名は `index.html` の `FIELDS` のキー） |
| `?tab=sheet` | 全レイヤー一覧を開いた状態にする（印刷したいとき） |
| `?selftest=1` | 幾何のセルフテストを実行し、結果をページ先頭に表示する |

### コマンド出力の使い方

座標はすべて相対（`~`）です。データパックの `data/<名前空間>/function/build.mcfunction` に置いて、
建てたい場所で `/function <名前空間>:build` を実行してください。原点は図面の左上ではなく、
半径で指定する形状では**中心**です（テキスト図面のヘッダーに、左上のセルの座標が出ます）。

## 図面の読み方

| 記号 | 意味 |
| --- | --- |
| `#` | ブロック |
| `^` `>` `v` `<` | 階段ブロック。**矢印は上り方向**で、そのまま `facing` の値になる |
| `+` | 隅棟（寄棟屋根の角） |
| `|` | 柱 |
| `.` | 空 |

画面上では、外側に面しているブロック（輪郭）だけ色を変えています。数える必要はありません。
どちらも同じブロックです。

### 階段の向きについて

階段ブロックの `facing` は**上り方向と一致します**。`facing=east` の階段はモデルの高い側が
+X（東）にあるので、西から東へ上ることになります。切妻屋根なら、西側の斜面は棟に向かって
東へ上るので `facing=east`、東側の斜面は `facing=west` です。

## 仕組み

`index.html` の 1 ファイルだけで完結しています。ビルド不要、依存パッケージなし、オフラインで動作します。
設定ジェネレータ（[`../`](../README.md)）と同じ作り方です。

- **`state` が唯一の真実**。フォームは `state` を書き換えるだけ
- 生成は **state → グリッド の純粋関数**（`buildCylinder` / `buildSphere` / `buildCone` /
  `buildGable` / `buildHip` / `buildShed` / `buildSpiral` / `buildArch`）。
  描画・テキスト・コマンドはすべてこのグリッドから作る

### 形状の作り方

**円のラスタライズ**は `(dx/ax)² + (dz/az)² <= 1`。半軸 `ax` は、
奇数直径なら `r + 0.5`（中心がブロック、幅 `2r+1`）、偶数直径なら `r`（中心が 2×2 の境目、幅 `2r`）。
`r + 0.5` を使うのは、`r` のままだと上下左右の端が細くとがるためです。半径 5 なら、
よく知られている直径 11 の円と一致します。

**空洞化**は、内側の楕円を引き算するのではなく、**6 近傍による収縮（`erode`）との差**で出しています。
引き算だと曲率が急なところで殻に穴が開きますが、収縮の差なら厚みがどこでも一定になり、必ず閉じます。
`openBottom` / `openTop` は「範囲外を中身とみなす」指定で、ドームの底や円柱の上下に
蓋ができるのを防ぐために使います。円柱・球・ドーム・円錐はすべてこの 1 つの経路（`fillSolid`）です。

**円錐**だけは、層ごとの半径を**整数に丸めてから**円にしています。丸めずに半径を連続的に縮めると、
途中の層に 1 マス幅のとげが出ます。丸めると、どの層も普通の円になります
（同じ半径が 2 段続くことがありますが、それは実際に積む形と同じです）。
球はこの丸めをしていません。3 次元の距離で決まる形をそのまま出したほうが、
他の球ジェネレータの結果と一致するためです。

**アーチ**は、開口（通り抜けるほう）を半楕円で作り、それを厚みの分だけ**ふくらませた差**を輪にします。
楕円を 2 つ引き算するやり方だと頂部の厚みが一定にならず、輪が閉じないことがあります。

**寄棟屋根**は、四辺からの距離の最小値がその層の帯に入るセルを置きます。
X 側と Z 側の斜面が同時に当たるセルが隅棟、向かい合う斜面が出会うセルが大棟です。

## テスト

幾何の不変条件のテストがページ自体に入っています。ブラウザで `index.html?selftest=1` を開くと
結果が出ます。ヘッドレスでも実行できます。

```bash
# ローカル（このリポジトリの開発環境）
/opt/pw-browsers/chromium_headless_shell-*/chrome-linux/headless_shell \
  --disable-gpu --no-sandbox --virtual-time-budget=3000 \
  --dump-dom "file://$PWD/app/minecraft/index.html?selftest=1" | grep -o 'SELFTEST: .*failed'
```

見ているのは、たとえば次のようなことです。

- 円が 4 回対称で、各行に穴が開いていない
- 中実の球のブロック数が `4/3πr³` とおおむね一致する
- 空洞の球の内側から外へ漏れない（殻が閉じている）
- 円錐の各層が、同じ半径の円ジェネレータの出力と一致する
- 切妻屋根が左右対称で、階段の向きが左右で逆になる
- 螺旋階段の隣り合う段が飛ばない（飛ぶ設定では警告が出て、推奨の段数が提示される）
- `.mcfunction` の行数がブロック数と一致する

CI（`.github/workflows/pages.yml`）でも同じテストが走り、**1 件でも失敗するとデプロイされません。**

## 既知の制限

- 螺旋階段の各段は宙に浮いた階段ブロックです（マイクラでは支えが要らないのでそのまま置けます）。
  下を埋めたい場合は、図面の位置を見ながら手で足してください
- 図面は 1 ブロック単位です。ハーフブロックや上下反転の階段は扱いません
- `.mcfunction` は `setblock` を 1 行ずつ出します。大きな形では行数が数万になります
